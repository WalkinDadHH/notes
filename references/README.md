# 参考资料 references/

本目录存放笔记的**源参考资料**（教材、讲义 PDF、截图等），按科目归类。

> ⚠️ 本目录位于 `docs/` 之外，**不会被 MkDocs 构建发布到站点**，仅作仓库内部归档与写作参考之用。请勿将受版权保护的完整教材公开发布。

## 目录结构

- `math-ode/` —— 常微分方程相关讲义与计算题整理 PDF
- `thermodynamics/` —— 工程热力学参考教材（何雅玲《精要分析及典型题精解》）
- `misc/` —— 暂未归类的截图等（无笔记引用）

> 注：被笔记页面以 iframe 嵌入的 PDF（如工程力学、光学复习讲义）仍保留在对应的 `docs/` 目录中，属于已发布内容，不在此归档。
